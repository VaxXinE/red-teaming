# Module 18 — Active Directory Fundamentals

Fondasi Active Directory untuk Red Team learning path berbasis Omarchy / Arch Linux. Modul ini fokus pada mental model dan read-only observation sebelum masuk ke Active Directory enumeration dan attack paths.

## Deliverables

- `docx/Red-Team-Module-18-Active-Directory-Fundamentals-Omarchy.docx`
- `pdf/Red-Team-Module-18-Active-Directory-Fundamentals-Omarchy.pdf`
- `labs/` — helper read-only untuk workspace, DNS SRV, DN parsing, domain/Kerberos/GPO/trust inventory, dan topology map.

## Safety

Gunakan hanya pada lab pribadi, GOAD/MINILAB yang terisolasi, CTF, atau platform yang memberikan authorization. GOAD sengaja vulnerable dan tidak boleh diekspos ke internet.

## Suggested order

1. Baca PDF sampai bagian authentication dan policy.
2. Jalankan lab workspace + standalone Windows inventory.
3. Jika punya AD lab, lanjut DNS SRV, Kerberos, GPO, trust, dan object inventory.
4. Selesaikan capstone topology map.
