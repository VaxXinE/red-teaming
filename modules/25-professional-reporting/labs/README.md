# Module 25 Labs

Safe reporting utilities only. They create local workspaces, finding/report templates, hash evidence, build evidence indexes, perform simple qualitative risk training, and lint Markdown reports for missing sections/placeholders/obvious secret patterns.

`severity-matrix.py` is a training matrix and is **not CVSS**. Use FIRST CVSS v4.0 only when the engagement requires CVSS and always publish the vector with the score.
