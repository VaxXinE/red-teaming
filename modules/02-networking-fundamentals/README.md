# Module 02 - Networking Fundamentals for Red Teamers

Fokus: TCP/IP, Ethernet/MAC/ARP, IPv4 subnetting, routing/NAT, TCP/UDP, DNS, ICMP, IPv6 basics, iproute2/ss, tcpdump/Wireshark, Docker networking, dan local service discovery dengan Nmap.

## Safety

Semua active scanning dan packet capture pada modul diarahkan ke localhost atau isolated Docker lab milik sendiri. Jangan mengganti target dengan jaringan publik, kantor, kampus, atau sistem pihak lain tanpa authorization.

## Files

- `pdf/` - modul final untuk belajar
- `docx/` - editable source
- `labs/network-baseline.sh` - read-only network baseline
- `labs/docker-lab.sh` - create/status/cleanup isolated Docker networking lab
