# Module 19 Labs

Read-only enumeration helpers for an **authorized Active Directory lab**. Use GOAD/MINILAB, HTB/THM, a domain you own, or a written-scope engagement.

## Safety rules

- Do not put passwords in command-line arguments or commit credential material.
- Do not run broad host/session collection unless the lab objective/RoE requires it.
- These helpers do not perform password spraying, Kerberoasting, remote execution, ACL modification, persistence, or privilege escalation.
- Treat LDAP/SMB/BloodHound output as sensitive assessment evidence.
