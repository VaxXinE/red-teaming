## Focus

Windows security model, SID/access tokens/UAC, local users/groups, NTFS ACLs, processes, services, scheduled tasks, registry, Event Logs, networking, PowerShell object pipelines, Sysinternals, and a safe Omarchy Windows VM workflow.

> Use only on systems you own or are explicitly authorized to assess. Module 04 is fundamentals/observation oriented and does not include privilege escalation or credential dumping.
