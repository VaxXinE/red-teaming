# Module 01 - Linux Fundamentals for Red Teamers

Omarchy / Arch Linux edition.

## Contents

- `pdf/` - final learning module.
- `docx/` - editable source document.
- `labs/system-survey.sh` - read-only local system survey mini-project used by the module.

## Safety

Run hands-on exercises only on systems you own or are explicitly authorized to assess. Do not commit raw evidence files (hostnames, usernames, internal IPs, process arguments, logs, credentials, tokens, or other sensitive data) to a public repository.

## Suggested workflow

1. Read the PDF section.
2. Re-run the command manually on your own Omarchy host.
3. Explain the output in your own words.
4. Complete the corresponding hands-on lab.
5. Complete the 30-minute practical challenge before Module 02.
