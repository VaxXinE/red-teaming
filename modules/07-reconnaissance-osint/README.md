# Module 07 - Reconnaissance & OSINT

Module ini mengajarkan reconnaissance yang scope-aware: RDAP, DNS, Certificate Transparency, search-engine recon, document metadata, local fingerprinting, asset provenance, dan attack-surface inventory.

## Safety Boundary

- Public discovery does **not** expand authorization.
- Active interaction di lab dibatasi ke localhost atau aset yang secara eksplisit dimiliki/diotorisasi.
- Jangan menjalankan brute-force DNS, broad crawling, atau automated active recon terhadap organisasi acak.
